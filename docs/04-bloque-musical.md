# 4. Bloque musical

**Qué es.** Una **agrupación de frases** que forma una unidad mayor y tiene su propia dirección: prepara, desarrolla energía y conduce a un punto de cierre o de cambio. Es lo que en una canción llamamos estrofa, estribillo o parte instrumental.

**Cómo reconocerlo.** Cambia algo perceptible: más o menos instrumentos, otra intensidad, un silencio significativo, un cambio de patrón rítmico.

```
Frase + Frase + Frase + Frase  =  BLOQUE (ej. estrofa)
```

| Bloque típico | Función |
|---|---|
| Estrofa | Cuenta, desarrolla, energía contenida |
| Pre-estribillo | Sube la tensión |
| Estribillo | Momento central, el más reconocible |
| Parte instrumental | Respiro o lucimiento |

**Jerarquía.** pulso → compás → frase → **bloque** → canción.

**Para el bailero.** Leer el bloque permite anticipar, acumular tensión y decidir cuándo expandirse y cuándo contenerse.

## Actividad
Con un cronómetro, anota el segundo en que empieza cada bloque y ponle nombre (estrofa, estribillo…). Después cuenta cuántas frases tiene cada uno.
